# Rinal Trans

Website informasi layanan sewa mobil. Pengunjung dapat melihat pilihan armada dan menghubungi Rinal Trans melalui WhatsApp untuk menanyakan ketersediaan atau pemesanan.

## Fitur

- Katalog armada dengan foto kendaraan.
- Tautan WhatsApp untuk menghubungi penyedia layanan.
- Navigasi responsif dan pengaturan tema terang atau gelap.

## Menjalankan secara lokal

Buka `index.html` di browser. Situs ini menggunakan HTML, CSS, dan JavaScript tanpa langkah build. Gambar kendaraan berada di folder `car/`, sedangkan aset situs lainnya berada di `img/`.

[Lihat website](https://rinaltrans.vercel.app/)
